ทำไม list comprehension ถึงเร็วกว่า for loop ปกติ?
ลอง benchmark ดูแล้วพบว่า list comprehension เร็วกว่า for loop ประมาณ 30% แต่ไม่เข้าใจว่าทำไม Python ทำงานต่างกันยังไงใต้ฝาครอบ?
# ทดสอบ import timeit lc = timeit.timeit('[x**2 for x in range(1000)]', number=10000) fl = timeit.timeit(''' r=[] for x in range(1000): r.append(x**2) ''', number=10000) print(f"LC: {lc:.3f}s Loop: {fl:.3f}s")
