ผู้เริ่มต้น
อะไรคือผลลัพธ์ของโค้ดนี้?
data = [10, 20, 30, 40, 50]
print(data[2])
ถูกต้อง! Index เริ่มที่ 0 ดังนั้น data[2] = 30 (index 0=10, 1=20, 2=30)
ไม่ถูก Index เริ่มที่ 0 ดังนั้น data[0]=10, data[1]=20, data[2]=30

ผู้เริ่มต้น
range(5) สร้างตัวเลขชุดใด?
ถูกต้อง! range(n) สร้างตัวเลข 0 ถึง n-1 ดังนั้น range(5) = 0,1,2,3,4
ไม่ถูก! range(n) สร้าง 0 ถึง n-1 (ไม่รวม n) ดังนั้น range(5) = 0,1,2,3,4
คะแนน: 0 XP
ปานกลาง
โค้ดนี้จะ print กี่ครั้ง?
for i in range(2, 8, 2):
    print(i)
เยี่ยม! range(2,8,2) = 2,4,6 → 3 ค่า (step=2, หยุดก่อนถึง 8)
ไม่ถูก! range(2,8,2) = 2,4,6 → 3 ค่าเท่านั้น (step=2 ข้ามทีละ 2)

ปานกลาง
Method ใดใช้เพิ่มสมาชิกท้าย List?
ถูกต้อง! .append(x) เพิ่มค่า x ที่ท้าย list เสมอ ส่วน .insert(i,x) ใส่ที่ตำแหน่ง i
ไม่ถูก! ใน Python ใช้ .append() สำหรับเพิ่มท้าย list (.add เป็นของ set, .push ไม่มีใน Python)

enumerate() ให้ค่าอะไรในแต่ละรอบ?
items = ["a", "b", "c"]
for ??? in enumerate(items):
    ...
เจ๋ง! enumerate() ส่งคืน tuple (index, value) ทำให้ใช้ได้เหมือน: for i, v in enumerate(items)
ไม่ถูก! enumerate() ส่งคืน tuple (index, value) เสมอ เช่น (0,'a'), (1,'b'), (2,'c')
