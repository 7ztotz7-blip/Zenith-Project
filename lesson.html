Index เริ่มที่ 0 เสมอ — ไม่ใช่ 1! สมาชิกตัวแรกคือ list[0] และตัวสุดท้ายคือ list[-1]

สร้าง list ด้วยวงเล็บเหลี่ยม [] คั่นด้วยจุลภาค สามารถเก็บข้อมูลต่างชนิดกันได้ในตัวแปรเดียวกัน

for Loop — วนซ้ำแบบ Pythonic

for loop ใน Python ออกแบบมาให้สวยงาม วนผ่านทุกสมาชิกใน list โดยตรง ไม่ต้องใช้ index เลย

📌 Pattern ที่ควรจำ

ถ้าต้องการทั้ง index และ value ใช้ enumerate() — จะได้ทั้งคู่ในคราวเดียว แบบ Pythonic ที่สุด

range() function

range(n) สร้างตัวเลข 0 ถึง n-1 ใช้เมื่อต้องการวนซ้ำตามจำนวนรอบ

range(start, stop, step) ควบคุมได้ละเอียดขึ้น เช่น range(0, 10, 2) คือ 0,2,4,6,8
